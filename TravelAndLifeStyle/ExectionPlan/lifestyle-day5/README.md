# Lifestyle · Day 5 handoff for Claude Code (Travel profile + Inspire me)

Adds Day 5 to the project after Day 2. Nothing here replaces a Day 1 or Day 2 file.

## Use it
1. Unzip into Downloads (you get `~/Downloads/lifestyle-day5`).
2. When Day 2 is finished, open Claude Code on the same project folder.
3. Paste the one prompt from PROMPTS-day5.md. Claude Code copies these files into the project, updates CLAUDE.md, and builds Day 5.

## What's inside
| Path | What it is |
|---|---|
| PROMPTS-day5.md | One hands-off prompt, plus step-by-step prompts |
| docs/day5-spec.md | Flow, layouts per device and pose, new components, save rules, Inspire me rules, models, acceptance |
| docs/day5-notes.md | Decisions from the design session, and the Day 5 requirements transcribed |
| docs/sample-data-day5.json | Mock data: customer record, preference catalog, empty and saved preference records, save API, validation, Inspire me response |
| design/screens/day5/ | 24 PNG screenshots (2x) |
| design/artboards/day5/ | The same 24 screens as HTML with exact values |

No new images: Day 5 uses images that came with Day 1 (`design/assets`).
