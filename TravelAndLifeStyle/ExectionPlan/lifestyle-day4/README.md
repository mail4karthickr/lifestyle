# Lifestyle · Day 4 handoff for Claude Code (My trips + itinerary)

Adds Day 4 to the project after Days 2 and 3. Nothing here replaces an earlier file; Day 4 does change two earlier pieces (My plans becomes My trips, and trip indicators become Stay and Dining only), which the prompt covers.

## Use it
1. Unzip into Downloads (you get `~/Downloads/lifestyle-day4`).
2. When Day 3 is finished, open Claude Code on the same project folder.
3. Paste the one prompt from PROMPTS-day4.md. Claude Code copies these files into the project, updates CLAUDE.md, and builds Day 4.

## What's inside
| Path | What it is |
|---|---|
| PROMPTS-day4.md | One hands-off prompt, plus step-by-step prompts |
| docs/day4-spec.md | Screens, layouts per device and pose, components, matching and tile rules, models, acceptance |
| docs/day4-notes.md | Decisions from the design session, and the Day 4 requirements transcribed |
| docs/sample-data-day4.json | Mock data: bookings (Houston hotel and dinner, Kesselhorn hotel), seeded flights, the rules, expected tiles for each case, expected itinerary |
| design/screens/day4/ | 15 PNG screenshots (2x), including D4-Tile-States, every case side by side |
| design/artboards/day4/ | The same 15 screens as HTML with exact values |

No new images: Day 4 uses images that came with Day 1 (`design/assets`).
