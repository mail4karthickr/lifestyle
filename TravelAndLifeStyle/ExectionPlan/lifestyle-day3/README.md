# Lifestyle · Day 3 handoff for Claude Code (Reserve a table)

Adds Day 3 to the project after Day 2. Nothing here replaces an earlier file.

## Use it
1. Unzip into Downloads (you get `~/Downloads/lifestyle-day3`).
2. When Day 2 is finished, open Claude Code on the same project folder.
3. Paste the one prompt from PROMPTS-day3.md. Claude Code copies these files into the project, updates CLAUDE.md, and builds Day 3.

## What's inside
| Path | What it is |
|---|---|
| PROMPTS-day3.md | One hands-off prompt, plus step-by-step prompts |
| docs/day3-spec.md | Flow, layouts per device and pose, new components, inventory and payment rules, models, acceptance |
| docs/day3-notes.md | Decisions from the design session, and the Day 3 requirements transcribed |
| docs/sample-data-day3.json | Mock data: restaurant record, hard-coded setup and seeded bookings, expected availability, reservation request/result, policy, validation, mock API scenarios, expected itinerary |
| design/screens/day3/ | 31 PNG screenshots (2x) |
| design/artboards/day3/ | The same 31 screens as HTML with exact values |

No new images: Day 3 uses images that came with Day 1 (`design/assets`).
