# Lifestyle · Day 2 handoff for Claude Code (Book a hotel)

Adds Day 2 to the Day 1 project. Nothing here replaces a Day 1 file.

## Use it
1. Unzip into Downloads (you get `~/Downloads/lifestyle-day2`).
2. Open Claude Code on your Day 1 project folder.
3. Paste the one prompt from PROMPTS-day2.md. Claude Code copies these files into the project, updates CLAUDE.md, and builds Day 2.

## What's inside
| Path | What it is |
|---|---|
| PROMPTS-day2.md | One hands-off prompt, plus step-by-step prompts |
| docs/day2-spec.md | Flow, layouts per device and pose, new components, rules, money math, models, acceptance |
| docs/day2-notes.md | Decisions from the design session, and the Day 2 requirements transcribed |
| docs/sample-data-day2.json | Mock data: existing trip with flights, 10 hotels, details, rooms and rates, reprice scenarios, payment, booking result, itinerary |
| design/screens/day2/ | 33 PNG screenshots (2x) |
| design/artboards/day2/ | The same 33 screens as HTML with exact values |
| design/assets/room_suite.webp | New room image (the others came with Day 1) |
